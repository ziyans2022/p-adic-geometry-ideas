# p-adic-geometry-ideas
A research skill for generating open problems in p-adic geometry. Compatible with Hermes, Codex and Claude Code
-----

## What it does

Ask about a research area, get back a structured problem:

- **Current state** — who proved what, exactly where the gap is
- **Precise problem statement** — conjecture or missing construction
- **First concrete step** — a specific computation or lemma to start with
- **3 papers to read** — to get up to speed
- **Dependencies** — which problems build on which

**Sub-areas covered:**

- Perfectoid spaces & diamonds
- p-adic Hodge theory
- Prismatic cohomology
- Rigid analytic geometry
- p-adic Langlands program
- p-adic Simpson correspondence
- Cross-area problems (60+ problems total)
-----

## Usage

The skill activates automatically when you mention relevant terms
(prismatic cohomology, Higgs bundles, p-adic Langlands, etc.)
or ask about research directions.

**Example prompts:**

```
What are accessible open problems in prismatic cohomology?
What's the current state of the p-adic Simpson correspondence?
Expand problem S3 to full format with a concrete first step.
Design a 3-year program starting from prismatic Dieudonné theory.
I just read Bhatt–Scholze prisms paper — what should I work on next?
```
